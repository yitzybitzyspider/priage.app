# PrIAge logo

The A in PrIAge is the heartbeat: its right leg carries on through the baseline into a single beat, then settles flat. Flat line: waiting. The beat: someone noticing. The I (serifed, so the name never reads as "Prlage") and the A are seat blue; the rest is ink.

Descriptor: "Better information for the people making the call".

## Files

| Use | File |
|---|---|
| Default (light backgrounds) | `priage-logo.svg`, `png/priage-logo.png` |
| On seat blue or dark | `priage-logo-reversed.svg`, `png/priage-logo-reversed.png` |
| One color | `priage-logo-black.svg`, `priage-logo-white.svg` (+ PNGs) |
| With descriptor | `priage-logo-tagline.svg`, `priage-logo-tagline-reversed.svg`, `png/priage-logo-tagline.png` |
| App icon / profile picture | `priage-icon.svg` (rounded), `priage-icon-round.svg`, `priage-icon-square.svg`, PNGs at 512 and 192 |
| Favicon (16 to 32 px) | `priage-icon-small.svg` (the A alone), `png/favicon-32.png`, `png/favicon-16.png` |
| Apple touch icon | `png/apple-touch-icon.png` (180) |

Colors: ink #1a1d1f, seat blue #2b5d87, pale blue on dark #cfe0ee. Typeface: Overpass 900 (letters converted to outlines in every file).

Regenerate: `build/export.html` (geometry, served over HTTP) then `build/outline.py` (outlines text with fontTools).
